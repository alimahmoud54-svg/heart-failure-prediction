# Heart Failure Prediction

A machine learning project that predicts heart failure risk
based on clinical records.

## Files
- `heart_failure_clinical_records_dataset.csv` : the dataset
- `Heart_Failure_Prediction_organized.ipynb` : data analysis and model training
- `model.h5` : the trained model
- `heart_failure_app.py` : the app that uses the model

## Built with
Python, Jupyter Notebook, Deep Learning
